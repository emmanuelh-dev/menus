# ESTRATEGIA SEO Y PALABRAS CLAVE (2026)

Este documento contiene la estrategia SEO y categorización de palabras clave para bysmax.com y sus subdominios (menús y moteles), basado en datos recientes de Search Console.

## 1. MENÚS DE RESTAURANTES (B2C)
Los usuarios tienen alta intención de descubrir menús actualizados, precios específicos al año en curso y promociones/combos.

### Keywords Principales:
- **Franquicias y Cadenas:** menu pollo loco, precios pollo loco 2026, paquetes pollo loco, menu carls jr 2026, starbucks precios 2026, menu super salads, toks menú y precios 2026, tim hortons menú precios 2026, menu ihop 2026.
- **Restaurantes Premium/Locales:** la madalena menu, la madalena san pedro menu precios, beluga menu monterrey, menu spikes 2026, azia menu, campomar menu, mochomos menu, roof acoxpa.

### Estrategia de Contenido:
- **Temporalidad:** Incluir explícitamente el año actual ("2026") en los títulos (Title Tags) y encabezados (H1/H2).
- **Intención de Búsqueda:** Los usuarios buscan "precios", "menú pdf", y "combos". Asegurar que estos datos sean visibles sin clics adicionales.
- **Localización:** Diferenciar por sucursal o ciudad si aplica (ej. "San Pedro", "Monterrey") en URLs y títulos.

## 2. MOTELES (B2C)
Las búsquedas se centran en consultar tarifas, tiempos de estadía (horas), ubicaciones y amenidades específicas.

### Keywords Principales:
- **Top Moteles (Búsquedas directas y precios):** motel love precios, motel hacienda cumbres, motel rio verde, motel niu, kyoto motel precios, motel marbella.
- **Moteles Boutique/Premium:** blue motel boutique, life motel boutique, m suites monterrey.
- **Búsquedas de Especialidad:** mejores moteles en monterrey, motel 12 horas monterrey, motel con jacuzzi monterrey, moteles mty.

### Estrategia de Contenido:
- **Datos Clave:** Destacar "Precios", "12 horas", "Fotos" y "Jacuzzi" en metadatos y contenido. Son los factores de decisión principales.
- **Agrupaciones:** Crear contenido tipo guías/listados (ej. "Los Mejores Moteles en Monterrey") para captar búsquedas exploratorias.
- **Claridad Visual:** Mantener la información clara y fácilmente escaneable sobre costos de estancia.

## 3. SOFTWARE Y MENÚ DIGITAL (B2B SaaS)
Palabras clave orientadas a dueños de negocios (restaurantes, bares, cafeterías) que buscan digitalizar su operación. (Simplificado de datos históricos).

### Keywords Principales:
- **Sistemas de Gestión:** software para restaurantes, sistema para restaurante, erp para restaurantes, sistema administrativo para restaurantes.
- **Punto de Venta (POS):** punto de venta restaurante, sistema pos para restaurantes, tpv para bares, pos para cafetería.
- **Menús Digitales:** menu digital qr, creador de menu digital, carta digital interactiva, hacer carta con codigo qr.
- **Operación y Comandas:** sistema de comandas para restaurantes, sistema de reservas online, sistema de cobro, facturación.
- **Segmentos Específicos:** software para comida rápida, sistema para pizzería, software para dark kitchen, programa para food truck.

### Estrategia de Contenido:
- **Enfoque de Solución:** Crear landing pages específicas para cada necesidad (ej. "Punto de venta para Pizzerías", "Menú digital para Bares").
- **Llamados a la Acción (CTAs):** Fricción baja, usar priorización de contacto rápido (WhatsApp/Formulario corto).
- **SEO de Comparación:** Abordar búsquedas relacionadas a alternativas destacando los diferenciadores de Bysmax frente a competidores.
